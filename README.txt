WEBSITE ROMANTIS UNTUK SALSA
=============================

Cara menjalankan:
1. Pastikan Python sudah terpasang.
2. Buka terminal di folder website_salsa.
3. Jalankan: pip install -r requirements.txt
4. Jalankan: python app.py
5. Buka browser: http://127.0.0.1:5000

Musik:
- Tombol musik memuat video "Perfect - Ed Sheeran" dari YouTube.
- Browser biasanya tidak mengizinkan autoplay, jadi pengunjung harus menekan tombol.
- Koneksi internet diperlukan untuk memuat musik YouTube.

Foto Salsa sudah disimpan di:
static/images/salsa.jpg

Untuk mengganti foto, ganti file salsa.jpg dengan foto lain dan gunakan nama file yang sama.
